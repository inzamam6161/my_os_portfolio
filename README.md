3. **SignalOps Mobile** — React Native, typed navigation, Redux Toolkit, persisted preferences and incident workflows.
4. **Experience** — professional summary, current timeline and selected engineering work.
5. **Skills & Tools** — evidence-backed capabilities instead of arbitrary proficiency percentages.
6. **Ask About Me** — deterministic recruiter assistant grounded in portfolio data.
7. **Contact** — direct professional contact routes.

## Recruiter positioning

The portfolio is intentionally optimized for React Native, mobile and frontend engineering opportunities in the UAE. Project claims and recruiter-assistant answers are scoped to evidence available in the portfolio and linked repositories rather than unsupported proficiency scores or production claims.
